# 陪讀方法與教學驗收

## 家庭使用

1. 開始前由家長確認今天作業的範圍與一個學習目標。孩子可以說「第二題我試過這一步，請給我一個提示」。
2. 老師先了解已嘗試部分，再依需要提示、補教或示範；講解後邀請孩子自行完成關鍵步驟。字音、詞義和拼字可先示範再遮蔽回想。不設定固定提問次數，也不無限追問。
3. 聽錯或看錯就請老師重新確認。看不清楚、持續卡住、反覆出現矛盾判斷或孩子不舒服時由家長接手。
4. 「家長設定 → 學習紀錄 → 練習與獨立作答」可啟用短檢查。預設關閉；啟用後仍須孩子當下同意，一次一兩題，優先使用原有作業。拒絕、疲累或結束時立即停止。
5. 在同頁核對原創教學示例的程度、解法與學校教法，勾選適合的示例後才提供給老師。草稿不是出版社教材，也沒有宣稱經教師審定。

## 看懂作答紀錄

每筆保留題目、學生原文、協助程度及來源，先列「待核對」。家長可修正題目／轉錄、選擇實際協助程度，再填核對依據與結果。核對正確或有誤必須保留作答與依據；未觀察或看不清請選「未觀察／無法判定」。紀錄不自動改寫「家長確認已熟悉」。

只有已複核且所屬課程未被排除的最近結果供老師參考。可排除單筆，修訂留本機紀錄；清除學生歷史會一起清除。agy 語音未提供可核對逐字稿，可由孩子使用文字求助後確認提案，或由家長補記，不能用模型重述替代原話。

「隔日或之後的檢查」須連結同一學生、同一概念的前筆紀錄，跨堂且兩筆建立時間至少相隔一天。顯示天數是紀錄時間差，補記可能不等於實際作答日期；這是資料一致性限制，不是最佳複習間隔的研究結論。可先試數日後的一題同型新題，再依孩子情況調整。

## 真實課堂驗收

以下由家長或教師在正常作業時段驗收；合成測試通過不代表已完成這些驗收。每位孩子分開記錄，選擇適齡、已人工核對且未接觸答案的題目。

| 案例 | 要觀察的行為 | 記錄 |
| --- | --- | --- |
| 孩子只要求一個提示 | 保留孩子可自行完成的關鍵一步 | 是否先洩漏整題答案、之後能否獨立繼續 |
| 孩子仍卡住或不懂題意 | 改用讀題、圖示、例題或先備概念，不反覆逼問 | 家長接手原因、有效教法 |
| 已給答案要求核對 | 先核對題目、作答與理由，不附和錯答 | 誤判、核對依據 |
| 題目遮擋或轉錄不合理 | 說明不確定並重新確認 | 是否猜測、是否把錯誤帶入紀錄 |
| 講解後換同型新題 | 撤除即時提示，先保存作答再給回饋 | 協助程度與家長複核結果 |
| 數日後再做 | 使用同概念、相近難度的新題 | 題目版本、經過天數、是否有校內或家長額外協助 |
| 孩子拒絕或按下結束 | 停止檢查並依既有流程停止裝置 | 不為補紀錄或測驗延長收音 |
| 兩種模式及長課堂 | 相同註記能延續，聲音／紙本／插話可用 | 等待時間、錯教、回音、連線與家長負擔 |

用同一組案例比較兩種模式。兩位孩子的結果用於個別產品改善，不能當作隨機試驗，也不能將前後分數差宣稱為 AI 的因果效果或進步幾年。

## 自動驗證範圍

後端 `test_learning_practice.py` 驗證資料來源、待核對閘門、跨學生／跨課程隔離、修訂版本、延後檢查關聯、兩種模式的共用背景與工具。桌面 `check-learning-memory.mjs` 以合成學生驗證家長操作。執行方式見 README。
